# Implementation Plan: Body Length Error vs Confidence Analysis

## Overview
This document outlines the implementation plan for creating an analysis script that evaluates the relationship between body length prediction error and bodypart confidence scores using frame-level aggregate results from cross-validation experiments.

## Implementation Approach

### Script Type: Standalone Analysis Script
Following the pattern of `analyze_cv_results.py` and `plot_lc_results.py`, we will create a standalone Python script with:
- Configuration constants at the top for easy modification
- Clear separation between configuration and implementation logic
- Helpful error messages and validation
- Console output with summary statistics
- High-quality plot generation

### File to Create

#### **NEW FILE**: `analyze_body_length_vs_confidence.py`
**Location**: Project root (same directory as `analyze_cv_results.py`, `run_cv.py`)

**Purpose**: 
- Load frame-level aggregate CSV files generated by User Story 02
- Calculate body length metrics (true, predicted, error)
- Calculate confidence metrics (mean, min)
- Generate scatter plot visualization
- Optionally save computed metrics to CSV

**Rationale for standalone script**:
- Follows existing codebase patterns (`analyze_cv_results.py`, `plot_lc_results.py`)
- Easy to run independently after CV completes
- Simple to modify configuration without touching core code
- No impact on existing workflows
- Can be integrated into `run_cv.py` later if desired

### 3. Core Functions to Implement

#### Function 1: `load_and_validate_data(input_file, bodypart_1, bodypart_2)`
**Purpose**: Load CSV and validate required columns exist

**Implementation**:
- Use `pd.read_csv()` to load the aggregate CSV
- Build list of required columns based on bodypart names:
  - `gt_{bodypart_1}_x`, `gt_{bodypart_1}_y`
  - `gt_{bodypart_2}_x`, `gt_{bodypart_2}_y`
  - `pred_{bodypart_1}_x`, `pred_{bodypart_1}_y`
  - `pred_{bodypart_2}_x`, `pred_{bodypart_2}_y`
  - `conf_{bodypart_1}`, `conf_{bodypart_2}`
- Check if all required columns exist in DataFrame
- Raise helpful error message if columns are missing
- Return validated DataFrame

**Reference**: Similar to column validation in `analyze_cv_results.py` lines 27-38

#### Function 2: `calculate_body_length_metrics(df, bodypart_1, bodypart_2)`
**Purpose**: Calculate body length and error metrics using vectorized operations

**Implementation**:
- Calculate true body length (vectorized):
  ```python
  df['true_body_length'] = np.sqrt(
      (df[f'gt_{bodypart_1}_x'] - df[f'gt_{bodypart_2}_x'])**2 +
      (df[f'gt_{bodypart_1}_y'] - df[f'gt_{bodypart_2}_y'])**2
  )
  ```
- Calculate predicted body length (vectorized):
  ```python
  df['pred_body_length'] = np.sqrt(
      (df[f'pred_{bodypart_1}_x'] - df[f'pred_{bodypart_2}_x'])**2 +
      (df[f'pred_{bodypart_1}_y'] - df[f'pred_{bodypart_2}_y'])**2
  )
  ```
- Calculate absolute error: `df['absolute_error'] = np.abs(df['pred_body_length'] - df['true_body_length'])`
- Calculate relative error: `df['relative_error'] = df['absolute_error'] / df['true_body_length']`
- Return DataFrame with new columns

**Reference**: Formula from `research_03.md` lines 498-520, based on SVL calculation in `deeplabcut/pose_estimation_pytorch/runners/train.py` lines 180-183

#### Function 3: `calculate_confidence_metrics(df, bodypart_1, bodypart_2)`
**Purpose**: Calculate confidence score aggregations

**Implementation**:
- Calculate mean confidence: `df['mean_confidence'] = (df[f'conf_{bodypart_1}'] + df[f'conf_{bodypart_2}']) / 2`
- Calculate min confidence: `df['min_confidence'] = df[[f'conf_{bodypart_1}', f'conf_{bodypart_2}']].min(axis=1)`
- Return DataFrame with new columns

**Reference**: User story requirements lines 50-53

#### Function 4: `filter_valid_data(df, min_body_length, confidence_threshold)`
**Purpose**: Filter out invalid or low-quality data

**Implementation**:
- Filter out frames where true_body_length is too small (avoid division by zero)
- Filter out frames where confidence is below threshold
- Drop rows with NaN values in critical columns
- Return filtered DataFrame and print statistics about filtering

**Reference**: Edge cases from `research_03.md` lines 541-555

#### Function 5: `generate_scatter_plot(df, experiment_id, landmark_set_name, output_dir, plot_settings)`
**Purpose**: Create and save scatter plot visualization

**Implementation**:
- Create figure with specified size: `plt.figure(figsize=plot_settings['figsize'])`
- Create scatter plot:
  ```python
  plt.scatter(df['mean_confidence'],
              df['relative_error'] * 100,  # Convert to percentage
              alpha=plot_settings['alpha'])
  ```
- Set axis labels:
  - X-axis: "Mean Confidence Score"
  - Y-axis: "Relative Error (%)"
- Add title: f"Body Length Error vs Confidence: {experiment_id} ({landmark_set_name})"
- Add grid: `plt.grid(True, alpha=0.3)`
- Optional enhancements:
  - Add horizontal reference lines at 5%, 10%, 20% error
  - Add vertical reference lines at 0.5, 0.7, 0.9 confidence
- Save to file: `body_length_error_vs_confidence_{experiment_id}_{landmark_set_name}.png`
- Use tight_layout() and specified DPI

**Reference**:
- User story requirements lines 55-64
- Plotting pattern from `plot_lc_results.py` lines 42-62
- Research example code lines 529-536

#### Function 6: `save_computed_metrics(df, experiment_id, landmark_set_name, output_dir)`

### 4. Main Function Flow

```python
def main():
    # 1. Construct input file path from configuration
    input_file = f'cv_frame_level_results_{EXPERIMENT_ID}_{LANDMARK_SET_NAME}.csv'
    input_path = os.path.join(OUTPUT_DIR, input_file)

    # 2. Check if file exists
    if not os.path.exists(input_path):
        print(f"Error: Frame-level results file not found: {input_path}")
        print(f"Please check that EXPERIMENT_ID='{EXPERIMENT_ID}' and "
              f"LANDMARK_SET_NAME='{LANDMARK_SET_NAME}' are correct.")
        sys.exit(1)

    # 3. Load and validate data
    print(f"Loading frame-level results from: {input_path}")
    df = load_and_validate_data(input_path, BODYPART_1, BODYPART_2)
    print(f"Loaded {len(df)} frames\n")

    # 4. Calculate body length metrics
    print("Calculating body length metrics...")
    df = calculate_body_length_metrics(df, BODYPART_1, BODYPART_2)

    # 5. Calculate confidence metrics
    print("Calculating confidence metrics...")
    df = calculate_confidence_metrics(df, BODYPART_1, BODYPART_2)

    # 6. Filter valid data
    print("Filtering valid data...")
    df_filtered = filter_valid_data(df, MIN_BODY_LENGTH_PIXELS, CONFIDENCE_THRESHOLD)
    print(f"Valid frames after filtering: {len(df_filtered)}\n")

    # 7. Print summary statistics
    print_summary_statistics(df, df_filtered)

    # 8. Generate scatter plot
    print("\nGenerating scatter plot...")
    plot_settings = {
        'figsize': PLOT_FIGSIZE,
        'alpha': PLOT_ALPHA,
        'dpi': PLOT_DPI,
        'max_error': MAX_RELATIVE_ERROR_DISPLAY
    }
    generate_scatter_plot(df_filtered, EXPERIMENT_ID, LANDMARK_SET_NAME,
                         OUTPUT_DIR, plot_settings)

    # 9. Optionally save computed metrics
    if SAVE_COMPUTED_METRICS:
        print("\nSaving computed metrics to CSV...")
        save_computed_metrics(df_filtered, EXPERIMENT_ID, LANDMARK_SET_NAME, OUTPUT_DIR)

    print("\nAnalysis complete!")
```

### 5. Entry Point

```python
if __name__ == "__main__":
    main()
```

# Goal
The overarching goal of this epic is to allow using limb length loss in a semi-supervised setting on unlabeled data. To achieve this, the following needs to take place:
- a new version of limb length loss needs to be implmented that uses prediction derived "body length" to scale the reference limb lengths rather than using the ground truth "body length" (which will not be available when training on unlabeled data). We should make sure that the function only provides calculates loss when we expect reasonably accurate predictions of body length. This will likely require a minimum confidence score for the bodypart predictions.
- as part of bootstrapping the semi-supervised training, we will want to determine how prediction confidence scores can be used to determine when to trust the predicted body length.  To do this, during bootstrapping on the labeled data, we will want to log the GT positions, predicted positions, and confidence scores for each bodypart on the test set during evaluation. This will allow us to calculate the true body length, the predicted body length, and the confidence scores for each bodypart. This data can then be used to determine a threshold for when to trust the predicted body length.
- we need to generate an unlabeled dataset from videos not in the labeled-data dir. Since we don't want too much data (and certainly don't want useless data), we should first run inference on the unlabeled videos using the bootstrapped supervised-only model to determine which frames have landmarks with sufficient confidence to be used for training. The landmarks used for calculating the body length should meet a minimum confidence threshold based on observations from the labeled data. The landmarks that are used in limb length loss should also meet a minimum confidence threshold, since the loss function only calculates a loss when it is provided reasonably accurate predictions and if too many instances have low confidence, there may be batches with no loss being calculated at all.
- once we have the new loss function that works on unlabeled data and the unlabeled dataset, we need to integrate the semi-supervised training into the existing supervised-onlyh training framework.
- - currently, labeled data is expected to be in the `labeled-data` dir. We will need to then create a new dataset from data in the `unlabeled-data` dir. This may or may not require creating a new dataset class. Whatever logic exists for the labeled dataset to determine which specimen a frame belongs to (for determining the reference body measurements) will need to be adapted for the unlabeled dataset.
- - the training step will need to be modified to optionally train on the unlabeled dataset (after training on the labeled dataset) in a given epoch. We will want to control the weight of the loss from the unlabeled data, how often we train on the unlabeled data (every X epochs), and when we start training on the unlabeled data (start epoch)
